# Ethical Hacking Notes

Bienvenido a mi base de conocimiento sobre Ethical Hacking.

Este repositorio documenta conceptos, laboratorios, metodologías, herramientas y aprendizajes relacionados con seguridad informática desde una perspectiva ética, defensiva y autorizada.

## Objetivo

Construir una base de conocimiento técnica y estructurada sobre:

- Fundamentos de ciberseguridad
- Ethical Hacking
- OSINT
- Seguridad ofensiva en entornos autorizados
- Seguridad defensiva
- Detección y análisis
