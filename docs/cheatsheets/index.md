# Cheatsheets

Esta sección funciona como una herramienta de referencia rápida para comandos, sintaxis y conceptos prácticos utilizados durante el curso.

El objetivo es reducir el tiempo de búsqueda y contar con una base de consulta rápida durante laboratorios, ejercicios y práctica técnica.

> Los cheatsheets están diseñados como material de apoyo y no reemplazan la explicación teórica del curso.

---

## Contenido

=== "Linux"
    Comandos esenciales de navegación, archivos, permisos, procesos, redes y utilidades comunes.

    Temas incluidos:
    - Navegación
    - Gestión de archivos
    - Permisos
    - Usuarios
    - Procesos
    - Networking
    - Logs

=== "Git"
    Comandos utilizados para versionamiento del conocimiento técnico y documentación.

    Temas incluidos:
    - Init
    - Add
    - Commit
    - Push
    - Pull
    - Branches


## Recomendación de uso

Durante laboratorios:

1. Intentar recordar el comando
2. Consultar el cheatsheet si es necesario
3. Entender qué hace el comando antes de ejecutarlo
4. Documentar observaciones relevantes

El objetivo es construir memoria técnica, no depender únicamente de copiar y pegar comandos.
