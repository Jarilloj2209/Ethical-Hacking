# Fundamentos de Ethical Hacking

Antes de aprender herramientas o técnicas, es importante comprender los conceptos fundamentales de seguridad informática.

En esta sección se documentan los principios básicos necesarios para entender el contexto del hacking ético y la ciberseguridad.

## Temas incluidos

1. ¿Qué es el hacking?
2. ¿Qué es un hacker?
3. Tipos de hacker
4. Conceptos básicos
5. Superficie de ataque
6. Triada CIA
7. Ética y legalidad

## Objetivo

Entender el lenguaje, conceptos y principios que forman la base del Ethical Hacking.
