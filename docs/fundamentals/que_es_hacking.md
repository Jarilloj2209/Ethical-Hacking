# ¿Qué es el hacking?

El hacking es el proceso de comprender, analizar y modificar el comportamiento de sistemas tecnológicos para identificar fallos, mejorar funcionalidades o evaluar seguridad.

En el contexto de ciberseguridad, el hacking se relaciona con la identificación de vulnerabilidades y el análisis del comportamiento de sistemas, redes o aplicaciones.

## Objetivos del hacking

- Comprender sistemas
- Identificar debilidades
- Evaluar seguridad
- Mejorar defensas
- Investigar tecnologías

## Mitos comunes

### “Hacking significa delinquir”
No necesariamente. El hacking puede ser ético, académico, defensivo o autorizado.

### “Un hacker siempre roba información”
El propósito depende del contexto, autorización y ética del actor.

## Conceptos clave

- Acceso autorizado
- Seguridad ofensiva
- Evaluación de riesgos
- Investigación técnica
