# ¿Qué es un hacker?
!!! note annotate "¿Qué es un hacker?(1)"

    Un hacker es una persona con conocimientos técnicos avanzados que comprende cómo funcionan sistemas tecnológicos y es capaz de analizarlos y manipularlos con el fin de realizar actividades para los que no fueron diseñados.

1.  El término no implica automáticamente una actividad ilegal.

## Características comunes

- Curiosidad técnica
- Pensamiento analítico
- Resolución de problemas
- Aprendizaje continuo
- Comprensión profunda de sistemas

## Diferencia entre hacker y ciberdelincuente

Un hacker puede actuar de forma ética o no ética.

Un ciberdelincuente realiza actividades ilegales con intención maliciosa, fraude, robo o daño.
