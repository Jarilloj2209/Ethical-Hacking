# Superficie de ataque

La superficie de ataque es el conjunto total de puntos por los cuales un sistema puede ser comprometido.

## Tipos

### Digital
- Aplicaciones web
- APIs
- Correos
- VPN

### Física
- USB
- Acceso físico
- Equipos desatendidos

### Humana
- Ingeniería social
- Phishing
- Manipulación psicológica
